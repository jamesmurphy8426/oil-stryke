In-car reminders

Browser notifications only fire while this app is open in a tab, so they can't hook directly into CarPlay or Android Auto connecting — that requires a native app. Until the native app ships, you can get a close approximation with your phone's own automation tools.

Set it up on iPhone (Shortcuts)
  1. Open the Shortcuts app → Automation tab → +
  2. Choose CarPlay as the trigger, set it to Is Connected
  3. Add an action: Open URL, pointing at wherever this app is hosted
  4. Turn off "Ask Before Running" so it opens automatically
This opens Odograph the moment CarPlay connects, so the mileage field is one tap away.
Set it up on Android (Tasker)
  1. Install Tasker from the Play Store
  2. Create a new profile → State → Net → Display Auto Interface On (or BT Connected for your car's Bluetooth name)
  3. Link it to a task with a Browse URL action pointing at wherever this app is hosted
Some Android Auto head units also support Android's car.CAR_CONNECTED broadcast, which Tasker can listen for directly.
